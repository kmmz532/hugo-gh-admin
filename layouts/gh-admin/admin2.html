サイト設定

ブログ名、ファビコン、記事カードのデフォルトサムネイルを変更する。変更内容はブログ本体の hugo.toml にコミットされ、次回のサイトビルドから反映される。

GitHub 認証

ブログ本体リポジトリ {{ $gh.siteRepo }} の Contents に書き込める権限が必要だ。

基本設定

ICO・PNG・SVGに対応。アップロードした画像はブログ本体リポジトリの static/ に保存する。

記事カード

記事に個別のサムネイルがない場合、記事カードにこの画像を表示する。未設定なら従来どおり画像を表示しない。OGP画像には適用しない。
